### How to Run

Make sure PostgresQL is installed properly. The JDBC driver is included as `postgresql-42.7.8.jar` in the root directory.

1. Compile the java file.
   `javac -cp ".;postgresql-42.7.8.jar" DatabaseCLI.java`
   
2. Run the application
   `java -cp ".;postgresql-42.7.8.jar" DatabaseCLI`
